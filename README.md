## 📌 Featured Projects

### 💰 [MoneyTalks](https://github.com/ciriciri123/MoneyTalks)
A computer vision-based currency recognition system designed to help visually impaired users identify Indonesian Rupiah denominations.

**Highlights**
- 1,319 images across 7 denominations
- Improved baseline accuracy from **59% to 81%**
- Used OpenCV, ORB, BoVW, SVM, OCR, and image preprocessing
- Flask-based web application with Supabase integration

### 📰 [Political Bias Classifier](https://github.com/ciriciri123/PoliticalBiasClassifier)
An NLP system for classifying political bias in news articles across five ideological categories.

**Highlights**
- 3,200+ articles from 1,900+ media outlets
- Preprocessing and feature engineering using Word2Vec, TF-IDF/N-grams, and NER
- Evaluated SVM, Naive Bayes, Logistic Regression, and Random Forest
- 0.97 precision, 0.95 recall, and 0.96 F1-score

### 🌊 [FloodCast](https://github.com/ciriciri123/FloodCast)
A research project investigating whether ENSO and IOD climate indicators can improve Jakarta flood prediction.

**Highlights**
- 208 monthly observations from January 2008 to April 2024
- Forecasting across 1–6 month horizons
- Feature engineering using ENSO and IOD indicators
- Best reported AUC of **0.7459**
- Research accepted to **ICICYTA 2026 (IEEE)**
